# ChatLab

ChatLab is a web-based AI chatbot that stays organized and coherent over long-running conversations, with project-level context that carries across chats.

## Key Features

- **OpenAI API chat** — conversational chat powered by OpenAI.
- **Conversation rolling memory** — long conversations automatically summarize their older turns, so context is preserved without sending the full history every time.
- **Automatic project-level rolling memory** — as you chat across a project, a project-wide summary updates automatically and carries into new conversations in that project.
- **Project organization** — group related conversations together with shared background context.
- **Highlights & notes** — save key parts of a response as a highlight with your own notes.
- **Temporary BTW side chat** — ask a quick side question about a specific response in a separate window, without it affecting the main conversation.
